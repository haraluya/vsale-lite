**修復建議**:
```typescript
// ❌ 錯誤做法
export async function deleteBackupJob(jobId: string) {
  const supabase = await createClient()
  // 直接執行刪除...
}

// ✅ 正確做法
export async function deleteBackupJob(jobId: string) {
  const { user, role } = await checkAuth()  // 新增權限驗證

  if (role !== 'admin') {
    return {
      success: false,
      message: '僅管理員可刪除備份任務'
    }
  }

  const supabase = await createClient()
  // 執行刪除...
}
```

### 2. API 錯誤處理不完整 (5 個)

#### 問題描述
多個 Server Actions 缺少 try-catch 錯誤處理機制，可能導致未預期的錯誤直接拋出到客戶端。

**影響範圍**:
- `lib/actions/tiers.ts:12` - `getTiers()`
- `lib/actions/reorder.ts:52` - 重新排序相關函式
- `lib/actions/helpers.ts:12` - 輔助函式
- `lib/actions/clients.ts:261` - 客戶管理函式
- `lib/actions/auth.ts:179` - 認證相關函式

**風險等級**: 🟡 **Medium** - 使用者體驗問題

**修復建議**:
```typescript
// ❌ 錯誤做法
export async function getTiers() {
  const supabase = await createClient()
  const { data, error } = await supabase
    .from('tiers')
    .select()

  return data  // 沒有錯誤處理
}

// ✅ 正確做法
export async function getTiers(): Promise<ActionResult<Tier[]>> {
  try {
    const supabase = await createClient()
    const { data, error } = await supabase
      .from('tiers')
      .select()

    if (error) throw error

    return { success: true, data }
  } catch (error) {
    console.error('取得會員等級失敗:', error)
    return {
      success: false,
      message: '無法載入會員等級資料，請稍後再試'
    }
  }
}
```

**預估修復時間**: 2 小時（5 個檔案）

## 🟡 中優先級問題 (P1)

### 3. 架構問題 - Server Actions 回傳型別不一致 (41 個)

#### 問題描述
大量 Server Actions 的回傳型別未遵循專案規範（`Promise<ActionResult<T>>`），導致型別安全性降低。

**統計資料**:
- 檢查函式總數: 177 個
- 符合規範: 136 個 (76.8%)
- 不符合規範: 41 個 (23.2%)

**常見模式**:
1. 查詢類函式直接回傳 `data` 而非 `ActionResult<T>`
2. 輔助函式未使用統一錯誤格式
3. 部分函式混用 `void` 與 `ActionResult`

**修復建議**:
制定統一的 Server Actions 開發規範，並逐步重構不符合規範的函式。建議優先處理：
1. 查詢類函式 (GET operations) - 15 個
2. 權限驗證相關函式 - 8 個
3. 輔助工具函式 - 18 個

**預估修復時間**: 1 天（批次處理）

---

### 4. 設計系統一致性問題 (25 個)

#### 問題描述
部分 UI 元件未完全遵循 Neo-Brutalism 設計規範，主要集中在測試頁面與早期開發的元件。

**問題分類**:
- **邊框響應式樣式** (12 個): 使用固定 `border-3` 而非 `border-2 md:border-3`
- **陰影響應式樣式** (8 個): 使用固定陰影而非 `shadow-neo-sm md:shadow-neo`
- **缺少點擊效果** (5 個): 未實作 `active:translate-x-[2px] active:shadow-none`

**影響範圍**:
- `/app/test-logo/` 測試頁面（可移除或更新）
- 早期開發的 UI 元件（需逐步重構）

**修復建議**:
1. **立即處理**: 刪除或更新 `/app/test-logo/` 測試頁面（不影響生產環境）
2. **排程處理**: 使用全域搜尋替換工具批次更新響應式樣式
3. **預防措施**: 在 ESLint 規則中新增設計規範檢查

**預估修復時間**: 4 小時
