## 🔧 常見問題修復

### 問題 1: 手機橫向滾動
- **原因**: 元素寬度超過 100vw
- **修復**: 檢查固定寬度、padding、margin

### 問題 2: 按鈕點擊區域太小
- **原因**: 未達 44px × 44px
- **修復**: 添加 `min-h-[44px]` 和適當的 padding

### 問題 3: 文字過小難以閱讀
- **原因**: 未使用響應式文字尺寸
- **修復**: 使用 `designTokens.typography`

### 問題 4: 圖片載入過大
- **原因**: 缺少 `sizes` 屬性
- **修復**: 添加適當的 `sizes` 到 Next.js Image

### 問題 5: Lighthouse 可訪問性評分低
- **常見原因**:
  - 缺少 aria-label
  - 色彩對比度不足
  - 表單缺少 label
  - Heading 層級跳躍
