## 測試項目

### 1. Excel 匯出功能

#### 1.1 基本匯出
- [ ] 訪問 `/admin/clients` 頁面
- [ ] 點擊「匯出 Excel」按鈕
- [ ] 應自動下載 Excel 檔案
- [ ] 檔名格式為 `客戶資料_YYYYMMDD.xlsx`
- [ ] 開啟 Excel 檔案，應包含以下欄位:
  - [ ] 手機號碼
  - [ ] 姓名
  - [ ] 會員等級
  - [ ] 建立時間
- [ ] 資料筆數與客戶列表一致
- [ ] 繁體中文正確顯示 (無亂碼)

#### 1.2 篩選後匯出
- [ ] 使用等級篩選器選擇特定等級
- [ ] 點擊「匯出 Excel」
- [ ] 應僅匯出該等級的客戶
- [ ] 匯出筆數與篩選結果一致

#### 1.3 搜尋後匯出
- [ ] 使用搜尋框輸入關鍵字
- [ ] 點擊「匯出 Excel」
- [ ] 應僅匯出符合搜尋條件的客戶

---

### 2. 範本下載功能

#### 2.1 基本下載
- [ ] 訪問 `/admin/clients` 頁面
- [ ] 點擊「下載範本」按鈕
- [ ] 應自動下載 `客戶匯入範本.xlsx`
- [ ] 開啟範本檔案，應包含:
  - [ ] 欄位標題列 (手機號碼、姓名、會員等級、密碼)
  - [ ] 一筆範例資料
  - [ ] 會員等級為系統現有等級

### 5. 錯誤處理測試

#### 5.1 檔案格式錯誤
- [ ] 上傳 .xls 格式檔案
- [ ] 應顯示「僅支援 .xlsx 格式」錯誤

#### 5.2 檔案過大
- [ ] 上傳超過 5MB 的檔案
- [ ] 應顯示「檔案大小不可超過 5MB」錯誤

#### 5.3 空檔案
- [ ] 上傳空白 Excel 檔案 (無資料列)
- [ ] 應顯示「Excel 檔案為空」錯誤

#### 5.4 超過筆數限制
- [ ] 上傳包含 1001 筆資料的 Excel
- [ ] 應顯示「單次匯入最多 1000 筆資料」錯誤
