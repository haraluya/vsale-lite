# US7 客戶資料批次匯入/匯出 Excel 功能 - 使用指南

**功能版本**: 1.0.0
**完成日期**: 2026-01-04
**分支**: 006-ux-enhancement

---

## 功能概述

User Story 7 提供完整的客戶資料 Excel 匯入/匯出功能，管理員可以:
- 一鍵匯出當前篩選的客戶資料為 Excel 檔案
- 下載匯入範本檔案 (含範例資料)
- 批次匯入客戶資料 (支援試算驗證模式)
- 查看詳細的匯入進度與錯誤報告

---

## 功能位置

- **頁面**: `/admin/clients` (客戶管理頁面)
- **權限**: 僅管理員可使用

---

## 使用方式

### 1. 匯出客戶資料

**操作步驟**:
1. 以管理員身分登入
2. 訪問 `/admin/clients` 頁面
3. (選用) 使用篩選器選擇會員等級或搜尋關鍵字
4. 點擊「匯出 Excel」按鈕
5. 系統自動下載 Excel 檔案 (檔名格式: `客戶資料_YYYYMMDD.xlsx`)

**匯出內容**:
- 手機號碼
- 姓名 (display_name)
- 會員等級
- 建立時間 (zh-TW 格式)

**範例檔案**:
```
| 手機號碼   | 姓名   | 會員等級 | 建立時間   |
|-----------|--------|---------|-----------|
| 0912345678| 王小明 | 批發    | 2026/1/4  |
| 0923456789| 李小華 | VIP     | 2026/1/3  |
```

---

### 2. 下載匯入範本

**操作步驟**:
1. 訪問 `/admin/clients` 頁面
2. 點擊「下載範本」按鈕
3. 系統下載 `客戶匯入範本.xlsx`

**範本內容**:
- 包含欄位標題與一筆範例資料
- 會員等級使用系統第一個等級作為範例

**Excel 欄位說明**:
| 欄位名稱 | 必填 | 格式 | 說明 |
|---------|------|------|------|
| 手機號碼 | 是 | `09xxxxxxxx` | 10 碼台灣手機號碼 |
| 姓名 | 是 | 2-50 字元 | 客戶顯示名稱 |
| 會員等級 | 是 | 文字 | 必須是系統現有的等級名稱 |
| 密碼 | 否 | 至少 6 字元 | 未填寫則使用手機後 6 碼 |

---

### 3. 批次匯入客戶資料

#### Step 1: 準備 Excel 檔案

**方式 A: 使用範本**
1. 下載匯入範本
2. 填入客戶資料 (最多 1000 筆)
3. 確保欄位格式正確

**方式 B: 自行建立**
1. 建立新的 Excel 檔案 (.xlsx 格式)
2. 第一列為欄位標題: `手機號碼`, `姓名`, `會員等級`, `密碼`
3. 從第二列開始填入資料

**範例資料**:
```
| 手機號碼   | 姓名   | 會員等級 | 密碼   |
|-----------|--------|---------|--------|
| 0912345678| 王小明 | 批發    | 123456 |
| 0923456789| 李小華 | VIP     | abc123 |
| 0934567890| 陳小美 | 零售    |        |
```

#### Step 2: 試算驗證 (建議)

**操作步驟**:
1. 訪問 `/admin/clients` 頁面
2. 點擊「批次匯入客戶資料」區塊的上傳區域
3. 選擇準備好的 Excel 檔案
4. 點擊「試算驗證」按鈕
5. 等待系統驗證 (不會寫入資料庫)

**驗證結果**:
- 總筆數
- 成功筆數 (格式正確且通過驗證)
- 錯誤筆數 (含詳細錯誤訊息)

**錯誤明細範例**:
```
第 3 列: 手機號碼
手機號碼格式錯誤 (需為 09xxxxxxxx)
值: 123

第 5 列: 會員等級
會員等級不存在
值: 高級批發

第 7 列: 手機號碼
手機號碼已存在
值: 0912345678
```

#### Step 3: 正式匯入

**操作步驟**:
1. 確認試算驗證結果無誤
2. 點擊「正式匯入」按鈕
3. 等待系統完成匯入
4. 查看匯入結果統計

**匯入結果**:
- 總筆數
- 成功筆數 (已建立客戶帳號)
- 錯誤筆數 (建立失敗，含詳細錯誤)

**匯入完成後**:
- 頁面自動重新載入
- 客戶列表更新
- 新增客戶可立即使用手機號碼登入

## 驗證規則

### 手機號碼
- **格式**: `09xxxxxxxx` (10 碼)
- **唯一性**: 不可重複 (已存在的手機號碼會被拒絕)
- **範例**: `0912345678`

### 姓名
- **長度**: 2-50 字元
- **範例**: `王小明`

### 會員等級
- **驗證**: 必須是系統現有的等級名稱 (大小寫需一致)
- **查詢**: 訪問 `/admin/tiers` 查看所有等級
- **範例**: `批發`, `VIP`, `零售`

### 密碼
- **長度**: 至少 6 個字元 (選填)
- **預設值**: 未填寫時使用手機號碼後 6 碼
- **範例**: `123456`, `abc123`

## 錯誤處理

### 常見錯誤與解決方式

#### 1. 檔案格式錯誤
**錯誤訊息**: "僅支援 .xlsx 格式"
**解決方式**: 確保檔案副檔名為 `.xlsx` (不支援 .xls 舊格式)

#### 2. 檔案過大
**錯誤訊息**: "檔案大小不可超過 5MB"
**解決方式**: 分批匯入，每批最多 1000 筆

#### 3. 手機號碼格式錯誤
**錯誤訊息**: "手機號碼格式錯誤 (需為 09xxxxxxxx)"
**解決方式**:
- 確保以 `09` 開頭
- 總共 10 碼
- 僅含數字
- Excel 中設定儲存格格式為「文字」避免自動轉換

#### 4. 會員等級不存在
**錯誤訊息**: "會員等級不存在"
**解決方式**:
- 訪問 `/admin/tiers` 查看正確的等級名稱
- 確保大小寫完全一致
- 範例: `批發` (正確) vs `批發 ` (多了空白, 錯誤)

#### 5. 手機號碼已存在
**錯誤訊息**: "手機號碼已存在"
**解決方式**:
- 檢查該客戶是否已在系統中
- 訪問 `/admin/clients` 搜尋該手機號碼
- 若需修改資料，使用「編輯客戶」功能而非重複匯入

## 進階技巧

### 1. 批次匯入前先試算
**建議流程**:
1. 上傳 Excel
2. 點擊「試算驗證」
3. 檢查錯誤明細
4. 修正 Excel 檔案
5. 重新上傳並試算
6. 確認無誤後點擊「正式匯入」

**優點**:
- 避免錯誤資料寫入
- 提前發現格式問題
- 節省修正時間

### 2. 使用篩選後匯出
**操作步驟**:
1. 使用等級篩選器選擇特定等級 (如「VIP」)
2. 點擊「匯出 Excel」
3. 僅匯出該等級的客戶

**用途**:
- 針對特定等級客戶進行分析
- 製作等級專屬的客戶名單
- 快速備份特定群組資料

### 3. Excel 儲存格格式設定
**問題**: 手機號碼自動轉換為數字 (如 `9.12345E+09`)
**解決方式**:
1. 選取手機號碼欄位
2. 右鍵 → 儲存格格式 → 文字
3. 重新輸入手機號碼

## 效能與限制

### 檔案限制
- **格式**: `.xlsx` (不支援 .xls, .csv)
- **大小**: 最大 5MB
- **筆數**: 單次最多 1000 筆

### 效能指標
- **100 筆匯入**: < 5 秒
- **500 筆匯入**: < 20 秒
- **1000 筆匯入**: < 40 秒

### 建議
- 資料量 > 500 筆時，建議分批匯入
- 匯入前先使用試算模式驗證
- 避免在尖峰時段匯入大量資料

## 技術細節

### Server Actions
- `exportClients(filters?)`: 匯出客戶資料
- `importClients(file, options?)`: 匯入客戶資料
- `downloadClientTemplate()`: 下載匯入範本

### UI 元件
- `<ExcelExport />`: 匯出按鈕元件
- `<ExcelImport />`: 匯入介面元件
- `<ExcelTemplateDownload />`: 範本下載按鈕元件

### 資料流程
```
匯出流程:
  篩選條件 → exportClients() → 查詢資料庫 → 產生 Excel → 下載

匯入流程 (試算):
  上傳檔案 → importClients(dry_run: true) → 驗證資料 → 回傳結果

匯入流程 (正式):
  上傳檔案 → importClients(dry_run: false) → 驗證資料 → 寫入資料庫 → 回傳結果
```

## 常見問題 FAQ

**Q1: 匯入後客戶密碼是什麼?**
A: 若 Excel 中未填寫密碼，系統自動使用手機號碼後 6 碼作為預設密碼。

**Q2: 如何修改已匯入的客戶資料?**
A: 請使用「客戶管理」頁面的「編輯」功能，不建議重複匯入。

**Q3: 匯入失敗會影響已建立的客戶嗎?**
A: 不會。匯入是逐筆處理，失敗的筆數不影響成功的筆數。

**Q4: 可以匯入管理員帳號嗎?**
A: 不可以。此功能僅用於匯入客戶 (role: client)，管理員需透過其他方式建立。

**Q5: 試算模式會寫入資料庫嗎?**
A: 不會。試算模式僅驗證資料格式，不執行任何寫入操作。

**Q6: 匯出的 Excel 可以直接用來匯入嗎?**
A: 可以，但需新增「密碼」欄位，否則系統會使用預設密碼。
