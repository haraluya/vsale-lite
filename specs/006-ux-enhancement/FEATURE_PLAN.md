# Vsale-lite UI/UX 優化與功能強化計畫
**Feature ID**: 006-ux-enhancement
**建立日期**: 2026-01-03
**狀態**: 規劃中
**優先級**: P1 (Core Enhancement)

---

## 📋 目標概述

在完成核心業務功能 (001-004) 後，本計畫聚焦於提升系統的使用者體驗、介面美化與操作效率。透過深化現有功能、新增視覺引導、優化互動流程，使 Vsale-lite 從「能用」進化到「好用且愛用」。

**核心目標**:
1. ✨ 提升前台客戶端操作效率 (搜尋、篩選、導航)
2. 🎨 美化後台管理端介面 (色彩分類、視覺層級)
3. 🚀 強化批次操作能力 (Excel 匯入匯出、批次設定)
4. 🏷️ 新增商品標籤系統 (tags)
5. 🎯 建立品牌識別 (Vsale Logo 設計)

---

## 🎯 使用者故事規劃

### 前台客戶端優化 (Mobile First)

#### US1: 全域搜尋與即時篩選
**角色**: 客戶
**需求**: 我希望在商店首頁快速找到想要的商品，不用一頁頁翻找
**功能**:
- 首頁頂部顯著位置提供搜尋欄
- 支援商品名稱、商品編號模糊搜尋
- 即時顯示搜尋結果 (< 300ms 響應)
- 使用防抖 (debounce) 優化效能

**驗收標準**:
- [x] 搜尋欄位置明顯，手機單手可觸及
- [x] 輸入 2 字元後開始搜尋
- [x] 搜尋結果即時更新，無需點擊按鈕
- [x] 搜尋時顯示載入指示器
- [x] 無結果時顯示友善提示

**優先級**: P0 (必須)

## 🗂️ 資料庫變更

### Migration: `20260109_add_product_tags.sql`

```sql
-- 新增商品標籤欄位
ALTER TABLE products
  ADD COLUMN tags TEXT[] DEFAULT '{}';

-- 建立 GIN 索引支援陣列查詢
CREATE INDEX idx_products_tags ON products USING GIN(tags);

-- 新增約束: 標籤數量不超過 5 個
ALTER TABLE products
  ADD CONSTRAINT check_tags_length
  CHECK (array_length(tags, 1) IS NULL OR array_length(tags, 1) <= 5);

COMMENT ON COLUMN products.tags IS '商品標籤陣列，如 {\"熱銷\", \"新品\", \"限量\"}';
```

### Migration: `20260110_add_order_delete_action.sql`

```sql
-- 新增訂單刪除操作類型到 order_timelines
-- (現有 type 已包含 'created', 'confirmed', 'cancelled' 等)
-- 確保 type 欄位支援 'deleted'

COMMENT ON COLUMN order_timelines.type IS '操作類型: created, confirmed, status_changed, cancelled, deleted';
```

## 🎨 UI/UX 設計規範

### 色彩系統 (品牌色彩)

建議在現有 Neo-Brutalism 黑白基礎上，新增品牌色彩:

| 用途 | 色彩 | Tailwind Class |
|------|------|----------------|
| 主色 (Primary) | 深藍 #1E40AF | `bg-blue-800` |
| 輔色 (Secondary) | 橘色 #F97316 | `bg-orange-500` |
| 成功 (Success) | 綠色 #22C55E | `bg-green-500` |
| 警告 (Warning) | 黃色 #EAB308 | `bg-yellow-500` |
| 錯誤 (Error) | 紅色 #EF4444 | `bg-red-500` |
| 資訊 (Info) | 藍色 #3B82F6 | `bg-blue-500` |

**使用原則**:
- 保留黑色邊框與硬邊陰影 (Neo-Brutalism 核心)
- 背景色使用品牌色淡化版 (如 `bg-blue-50`)
- 按鈕與卡片使用品牌色填充
