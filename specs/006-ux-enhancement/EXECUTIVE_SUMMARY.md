## 🎯 核心目標

將 Vsale-lite 從「功能完整的 MVP」提升為「使用者愛用的產品」，透過深化 UI/UX、新增快捷操作、建立品牌識別，打造差異化競爭力。

---

## 📊 功能概覽

### 前台客戶端 (4 項使用者故事)
1. **全域搜尋** - 首頁搜尋欄，即時查詢商品
2. **快速篩選** - 類別 + 標籤多選組合篩選
3. **導航優化** - Logo 回首頁 + 麵包屑
4. **視覺優化** - 色彩區分庫存狀態 + 標籤徽章

### 後台管理端 (6 項使用者故事)
5. **側邊欄分類** - 功能模組色彩與分隔線區分
6. **客戶快篩** - 等級切換 + 搜尋
7. **Excel 匯入/匯出** - 批次客戶資料處理
8. **訂單刪除** - 刪除 pending 狀態訂單
9. **商品標籤** - 新增 tags 欄位 + 批次設定
10. **儀表板視覺化** - 關鍵指標卡片 + 圖表 (選用)

### 品牌識別 (1 項)
11. **Vsale Logo** - Neo-Brutalism 風格 Logo 設計與整合

---

## 🗄️ 技術變更

### 資料庫 Migration (2 個)
1. `20260109_add_product_tags.sql` - 新增 `products.tags TEXT[]` 欄位
2. `20260110_add_order_delete_action.sql` - 支援訂單刪除操作記錄

### 新增套件 (2 個)
- `xlsx` - Excel 處理庫 (匯入/匯出)
- `recharts` - 圖表庫 (儀表板視覺化, 選用)

### 新增 Server Actions
- `searchProducts(query)` - 全域搜尋
- `filterProducts(filters)` - 組合篩選
- `exportClients()` - 匯出客戶 Excel
- `importClients(file)` - 匯入客戶 Excel
- `deleteOrder(orderId)` - 刪除訂單
- `batchUpdateProductTags(productIds, tags)` - 批次設定標籤

## 🎨 設計規範

### 色彩系統 (新增)
建議在現有黑白基礎上新增品牌色彩:
- **主色**: 深藍 `#1E40AF` (信任感)
- **輔色**: 橘色 `#F97316` (活力)
- **狀態色**: 綠/黃/紅 (成功/警告/錯誤)

### Logo 設計概念
```
圖示: V + 購物車組合
字體: 粗體無襯線 (與 Neo-Brutalism 一致)
格式: SVG (可縮放)
版本: 深色背景版 + 淺色背景版 + 圖示版 (Favicon)
```
