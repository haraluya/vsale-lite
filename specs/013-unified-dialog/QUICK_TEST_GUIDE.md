## 🔍 常見問題檢查

### 如果對話框沒有顯示
1. 檢查瀏覽器 Console 是否有錯誤
2. 確認已登入且有權限
3. 檢查 DialogProvider 是否已整合至 app/layout.tsx

### 如果樣式不正確
1. 清除瀏覽器快取
2. 執行 `pnpm dev` 重啟開發伺服器
3. 檢查 Tailwind CSS 是否正確載入

### 如果功能運作異常
1. 檢查 TypeScript 型別錯誤：`pnpm type-check`
2. 檢查 ESLint 錯誤：`pnpm lint`
3. 查看瀏覽器 Console 和 Network 面板
