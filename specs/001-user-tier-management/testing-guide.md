## 測試場景

### 場景 1: 會員等級管理 (User Story 1)

#### 測試目標
驗證管理員可以完整管理會員等級 (CRUD)

#### 測試步驟

1. **登入後台**
   - [ ] 訪問 `/admin/login`
   - [ ] 使用管理員帳號登入
   - [ ] 確認重導向至 `/admin/dashboard`

2. **查看會員等級列表**
   - [ ] 點擊側邊欄「會員等級」
   - [ ] 確認顯示預設等級 (零售、批發、經銷商)
   - [ ] 確認等級依 `rank` 排序顯示

3. **建立新等級**
   - [ ] 點擊「新增等級」按鈕
   - [ ] 輸入等級名稱: `VIP`
   - [ ] 輸入排序數字: `0`
   - [ ] 點擊「建立等級」
   - [ ] 確認顯示成功訊息
   - [ ] 確認重導向至等級列表
   - [ ] 確認 VIP 等級出現在第一位 (rank 最小)

4. **編輯等級**
   - [ ] 點擊某個等級的「編輯」按鈕
   - [ ] 修改等級名稱
   - [ ] 點擊「更新等級」
   - [ ] 確認更新成功並重導向

5. **刪除等級保護**
   - [ ] 嘗試刪除「零售」等級
   - [ ] 確認顯示錯誤訊息「此等級尚有客戶使用,無法刪除」
   - [ ] 刪除剛建立的「VIP」等級 (無客戶使用)
   - [ ] 確認刪除成功

**預期結果**: ✅ 所有 CRUD 操作正常,刪除保護生效

### 場景 2: 快速開戶 (User Story 2)

#### 測試目標
驗證管理員可以快速建立客戶帳號並取得登入資訊

#### 測試步驟

1. **訪問客戶列表**
   - [ ] 點擊側邊欄「客戶管理」
   - [ ] 確認顯示客戶列表 (或「尚無客戶資料」提示)

2. **建立新客戶**
   - [ ] 點擊「快速開戶」按鈕
   - [ ] 輸入手機號碼: `0912345678`
   - [ ] 選擇會員等級: `零售`
   - [ ] 輸入顯示名稱: `測試客戶 A`
   - [ ] 輸入備註: `測試用帳號`
   - [ ] 點擊「建立客戶」
   - [ ] 確認顯示成功訊息與登入資訊

3. **複製登入資訊**
   - [ ] 點擊「複製完整登入指引」按鈕
   - [ ] 確認按鈕文字變更為「已複製」
   - [ ] 打開記事本貼上,確認包含:
     - 前台網址
     - 登入電話
     - 登入密碼 (手機號碼後 6 碼: `345678`)

4. **手機號碼驗證**
   - [ ] 嘗試建立相同手機號碼
   - [ ] 確認顯示「此手機號碼已被使用」錯誤
   - [ ] 嘗試輸入錯誤格式 (如 `123`)
   - [ ] 確認顯示格式驗證錯誤

5. **建立更多測試客戶**
   - [ ] 建立客戶 B: `0923456789` / 批發 / `測試客戶 B`
   - [ ] 建立客戶 C: `0934567890` / 經銷商 / `測試客戶 C`

**預期結果**: ✅ 快速開戶成功,密碼生成正確,驗證機制生效

   - [ ] 選擇「全部等級」
   - [ ] 確認顯示所有客戶

   - [ ] 確認回到第 1 頁
