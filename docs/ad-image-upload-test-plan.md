## 測試步驟

### 準備工作

1. **確認當前 bucket 狀態**
   ```powershell
   npx tsx scripts/check-storage-buckets.ts
   ```

2. **檢查 storage policies**
   - 前往 Supabase Dashboard
   - 選擇對應站點專案
   - SQL Editor → 執行：
   ```sql
   SELECT policyname, cmd, roles::text[], qual, with_check
   FROM pg_policies 
   WHERE schemaname = 'storage' AND tablename = 'objects'
   ORDER BY policyname;
   ```
