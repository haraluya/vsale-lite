# 組合優惠與優惠券共用規則

## 組合優惠

- 支援「各選」與「任選」兩種模式
- 使用快照機制保存訂單時刻的組合優惠資訊（刪除後歷史訂單仍可顯示）
- 支援等級限制（不同會員等級看到不同組合優惠）
- 組合優惠商品與普通商品一樣扣減庫存

## 優惠券與組合優惠互動

### 互斥設定
優惠券允許組合優惠時，**不可**設定系列限制。

### 折扣基準計算

```
IF 優惠券允許組合優惠 AND 無系列限制 THEN
  折扣基準 = 普通商品總價 + 組合優惠優惠價
ELSE IF 優惠券有系列限制 THEN
  折扣基準 = 符合系列的普通商品總價
ELSE
  折扣基準 = 普通商品總價
```

- 運費計算基準：折扣前金額（普通商品 + 組合優惠優惠價）

## 訂單處理與庫存

- 訂單建立時建立完整快照（名稱、模式、系列、選購明細、價格）
- 支援純組合優惠訂單（無普通商品）
- 級聯刪除訂單時自動刪除組合優惠項目
- **出貨時**：扣減組合優惠中的商品庫存
- **取消時**：回補庫存（僅已出貨訂單）

## 購物車整合

- 組合優惠與普通商品可混合購物
- localStorage 持久化（版本化，支援遷移）
- 商品變更時自動重新驗證優惠券適用性

## 顯示規範

- 購物車：黃色背景（bg-yellow-50）區分一般商品
- 系列標籤：顏色編碼（紫/藍/綠/橙/粉/青）
- 倒數計時器：活動結束前 24 小時顯示
- 前後台訂單詳情：完整顯示組合優惠項目與折扣明細
